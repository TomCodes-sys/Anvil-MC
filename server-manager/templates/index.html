Connect Crafty to continue

Anvil Server Manager needs Crafty's own API to check real server status, trigger Crash Recovery restarts, and drive the Fleet view. Enter your API token below — the URL is filled in automatically since Crafty runs on this same machine.

How to get a Crafty API token
  1. Log into Crafty's web UI.
  2. Click your username (top right) → Profile.
  3. Scroll to the API Keys section → click Generate Key.
  4. Tick superuser if you want this to see every server, not just ones shared to that user.
  5. Copy the token immediately — Crafty only shows it once — and paste it below.

RCON console

A lightweight command box that talks directly to a server's RCON port — say, whitelist, tp, save-all, whatever — without needing Crafty's own console or SSH. Each server needs enable-rcon=true, an rcon.port, and an rcon.password set in its server.properties first.

Target server

Vanilla Bedrock dedicated servers don't support RCON at all — there's no protocol for it to connect to. This tab only works for Java servers.

Whitelist / ops / bans

      
A shared UI over each server's whitelist.json, ops.json, and ban lists — with a Mojang username lookup so you never have to hand-craft a UUID.

      
Bedrock's whitelist/permissions use a different file format than Java's (no UUIDs, no ops.json) — only whitelist add/remove is offered here for Bedrock servers; ops and ban management are Java-only for now.

Crash Recovery Tool

      
Watches every server linked to Crafty. On an unexpected stop (not one you triggered), it restarts the server automatically, saves a copy of its logs somewhere durable, and flags the world as possibly corrupt so you know to check before rejoining.
