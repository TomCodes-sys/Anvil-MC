before you start Prerequisites

Give this server a fixed IP address

So its address never changes and your setup keeps working. In your router, set a DHCP reservation (sometimes called a "static lease") for this MAC address:

--
Your router normally hands out IPs that can change over time (DHCP). If this server's IP changes, your router's port forwarding rules point at the wrong device and everything breaks silently. In your router's admin page, look for "DHCP Reservation" or "Static Lease," paste in the MAC address above, and give it a fixed IP. This is preferred over setting a static IP directly on Ubuntu, since it keeps everything configured in one place.
Make sure your ISP allows port forwarding (no CGNAT)

Some ISPs share one public IP between many houses — if that's you, port forwarding won't work.

This is called Carrier-Grade NAT (CGNAT). To check: compare your router's WAN/internet IP (found in its admin page) against what whatismyipaddress.com shows you. If they're different, you're behind CGNAT — port forwarding physically cannot work no matter how it's configured. Call your ISP and ask for a public IP (sometimes free, sometimes a small fee), or use a tunnel service like playit.gg or ngrok as a workaround.
Forward these ports on your router

Log into your router's admin page, find "Port Forwarding," and point these at this server's IP:

PortProtocolFor
25565 TCP Minecraft Java Edition
19132 UDP Minecraft Bedrock Edition
19134 UDP Additional Bedrock/companion server
19135 UDP Additional Bedrock/companion server
24454 UDP Voice chat (Simple Voice Chat mod)
Only forward the three ports above. Do not forward 8443 (Crafty) or 9090 (Cockpit) — those give control over the whole server and should stay on your home network only. TCP vs UDP matters: forwarding a port on the wrong protocol is a common reason Bedrock or voice chat "doesn't work" even though the rule looks right. Every router's UI is laid out differently, but you're always looking for a section named some variant of "Port Forwarding," "Virtual Server," or "NAT."
