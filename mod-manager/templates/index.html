Connect Crafty Controller to continue

Anvil Mod Manager needs a Crafty Controller API token before it can find your servers or install anything. Enter it below to unlock the dashboard — or just try Preview Mode with a demo server, no token required.

Getting your API token:

  1. Log into Crafty's web UI
  2. Click your username (top right) → Profile
  3. Scroll to the API Keys section → click Generate Key
  4. Tick superuser if you want it to see every server, not just ones shared to that user
  5. Copy the token immediately — Crafty only shows it once — and paste it below

Crafty Controller API

Connect Crafty once here — it powers the restart hook, the "pick your server" dropdown on Server Setup, live running-status dots, and blocking mod/plugin downloads while a server is running.

Getting your API token:

  1. Log into Crafty's web UI
  2. Click your username (top right) → Profile
  3. Scroll to the API Keys section → click Generate Key
  4. Tick superuser if you want it to see every server, not just ones shared to that user
  5. Copy the token immediately — Crafty only shows it once — and paste it below

Advanced: Crafty servers folder

Where each Crafty server's folder lives on this machine, so picking a server from the dropdown on Server Setup can find its files without you browsing manually. Defaults to /opt/crafty/servers — the path the Anvil Server Installer uses. Only change this if your Crafty install uses a different layout.

Which Crafty server each saved profile below maps to is set per-server in the Saved servers card on the Server Setup tab, not here.
